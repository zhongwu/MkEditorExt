# Rules for Claude in this repo

## Git

- **Never run `git commit` or `git push` without the user's explicit approval for that specific commit or push.** Make the changes, show what would be committed (files and message), and wait for a yes. Approval for one commit or push does not carry over to the next.
- Never add `Co-Authored-By` lines, model names or "Generated with Claude Code" lines to commit messages or pull request descriptions.

## Project

- The design and roadmap are in [PLAN.md](PLAN.md). Follow it, and update it when a decision changes.
